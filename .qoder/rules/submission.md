# The submission is the finish line

Every job in this repo feeds one of the 7 submission items, due before 15:00 today (2026-11-19, MYT):

1. Team name
2. Project name, description, track
3. Implementation and inspiration
4. Pitch deck link (5 min per team; slides: team name, track chosen, solution name, tech stack, Qoder usage, live demo)
5. Demo video link
6. Deployment link
7. GitHub link

Rules:
- Read `docs/SUBMISSION.md` before any work on the deck, video, README, deploy or copy. It holds the current values and cut-offs.
- Values come from `web/src/content/submission.ts`. Never hard-code a team, project or track name anywhere else.
- A value marked `TBD` stays `TBD`. Never invent one. Say so in your report.
- Qoder usage counts for judging: keep your report honest and short, because it is quoted on the "Qoder usage" slide.
